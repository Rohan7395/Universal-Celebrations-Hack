# Guardian alone decides Escalation

A missed emergency is the worst failure when caring for older adults, so Escalation is decided by one dedicated Platform Agent, Guardian, rather than by each Specialist. Fleet Agents may raise a Flag, but only Guardian escalates, judging against Baseline Rules (shipped with the platform, not removable) plus Agency Rules (set by the Agency Owner in the Onboarding Interview). Guardian is a Platform Agent rather than a Fleet Agent so that the safety floor is the same for every Tenant.

## Considered Options

- **Each Specialist escalates on its own judgement**: rejected because safety behaviour would then vary by agent and by Tenant, and be harder to test and explain.
